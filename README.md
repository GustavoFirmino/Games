# 🎮 Games

Coleção pessoal de jogos que eu faço **por hobby**, nas horas vagas.

Nada aqui é produto, startup ou projeto profissional — é só diversão, aprendizado e vontade
de construir coisas. Cada pasta é um jogo independente, com seu próprio README, código e
instruções de como rodar.

Fique à vontade para olhar o código, clonar, mexer e usar como quiser.

## 🗂️ Organização do repositório

```
Games/
├── README.md                 # este arquivo
├── LICENSE                   # MIT
├── .gitignore
├── docs/
│   └── CONTRIBUTING.md       # padrão para adicionar um novo jogo
└── CodigoSecreto/            # 1 pasta = 1 jogo
    ├── README.md
    ├── CodigoSecreto.xcodeproj
    └── CodigoSecreto/
        ├── App/
        ├── Models/
        ├── ViewModels/
        ├── Views/
        ├── Theme/
        └── Resources/
```

Cada jogo é autocontido: dá para abrir/rodar sem depender de nada fora da própria pasta.
